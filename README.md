硕策导航（Shuoce Navigation） 是一个轻量级的个人网络导航项目。

它没有复杂的商业定位，也没有庞大的用户体系。

项目最初只是为了把自己和朋友日常使用的网站、工具与资源集中到一个入口中，并在实际使用过程中持续进行整理、优化和维护。

«让上网，更简单。»
